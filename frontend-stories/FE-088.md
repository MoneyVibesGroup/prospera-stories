## User Story

En tant qu'**expert-comptable**,
je veux **voir d'un coup d'œil où en est la chaîne balance → passage → états → contrôle**,
afin de **savoir quelle étape me bloque sans ouvrir chaque onglet**.

---

## Contexte

`BILAN_TABS` (`src/features/bilan/config/nav.ts`) déclare déjà la chaîne, dans le bon ordre :

```
Balance source → Table de passage → États → Prévisionnel (FE-035) → Export (FE-038)
```

⚡ **Le module a donc déjà le squelette du pipeline de la fiche 6/7.** Ce qu'il n'a pas, c'est
l'**état** de chaque maillon : les onglets sont des liens inertes. Pour savoir si la table de
passage laisse des comptes de côté, il faut l'ouvrir ; pour savoir si le bilan s'équilibre, il
faut ouvrir les États.

⚠️ **Le champ `story` a déjà réglé la moitié du problème, et c'est le précédent à suivre.** Sa
raison est écrite dans le fichier : *« un onglet grisé muet dit seulement que quelque chose ne
marche pas »*. Un onglet **livré** mais muet sur son état dit la même chose en creux.

---

## Périmètre

**Inclus**

- Chaque onglet livré porte un **état lisible**, dérivé de ce que son écran a déjà chargé :

  | Étape | Ce que l'état dit | Source (déjà chargée) |
  |---|---|---|
  | Balance source | retenue / aucune | `balance-source-provider` |
  | Table de passage | *n* comptes non affectés / tous rattachés | `use-passage` |
  | États | s'équilibre / écart de *n* | `use-bilan` → `controle` |

- Trois états seulement : **fait**, **à traiter**, **pas encore atteignable**. Pas de
  pourcentage, pas de barre de progression — la chaîne n'est pas un assistant pas-à-pas.
- Un onglet non atteignable **dit pourquoi** (« aucune balance retenue »), il ne se grise pas
  en silence.

**Hors périmètre**

- Charger quoi que ce soit pour alimenter le fil. ⛔ **Si une donnée n'est pas déjà en cache,
  l'onglet reste neutre** — un fil qui déclencherait trois requêtes au montage du module
  coûterait plus qu'il n'apporte, et rendrait la navigation dépendante d'appels qui peuvent
  échouer.
- Empêcher la navigation. La chaîne **informe**, elle ne verrouille pas : l'expert-comptable
  ouvre ses onglets dans l'ordre qu'il veut.
- Les onglets non livrés (Prévisionnel, Export) : ils gardent leur mention de story, inchangée.

## Critères d'acceptation

- [ ] Les trois onglets livrés affichent leur état quand la donnée est en cache.
- [ ] Aucune requête réseau supplémentaire n'est émise au montage du module. **Témoin : test qui
      compte les appels.**
- [ ] Donnée absente du cache → onglet neutre, **jamais** un état inventé ni un « 0 ».
- [ ] Les onglets `story` (FE-035, FE-038) sont inchangés — témoin de non-régression sur
      `bilan-nav.test.tsx`.
- [ ] L'état « à traiter » de la table de passage et l'avertissement des comptes écartés des
      États **disent la même chose** : pas deux comptages différents du même fait.
- [ ] i18n FR ; tests de rendu par état ; accessibilité — l'état est dans le texte accessible,
      pas seulement dans la couleur.
